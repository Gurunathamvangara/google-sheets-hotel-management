# Google Sheets Structure - Complete Setup Guide

## 📊 All Sheet Tabs Required

### 1. **Dashboard** (Main Overview)
- Key metrics & KPIs
- Today's check-ins/check-outs
- Financial summary
- Housekeeping status
- Quick action buttons
- Alerts & notifications

### 2. **Reservations**
- Reservation ID
- Guest Name
- Check-in Date
- Check-out Date
- Room Number
- Room Type
- Rate per Night
- Total Nights
- Total Amount
- Payment Status
- Booking Source
- Status (Confirmed/Pending/Cancelled)
- Special Requests
- Notes

### 3. **Guests**
- Guest ID
- Full Name
- Email
- Phone
- Address
- City
- Country
- Date of Birth
- ID Type
- ID Number
- Preferred Room Type
- Dietary Restrictions
- Guest Preferences
- Loyalty Program #
- Total Stays
- Total Spent
- Last Stay Date
- Notes

### 4. **Rooms**
- Room Number
- Room Type
- Floor
- Capacity (Max Guests)
- Amenities
- Rate (Standard/Peak)
- Status (Available/Occupied/Maintenance)
- Last Cleaned
- Next Cleaning Due
- Condition Notes
- Features (AC, WiFi, TV, etc.)

### 5. **Housekeeping**
- Room Number
- Current Status (Clean/Dirty/Under Maintenance)
- Assigned Staff
- Check-in Time
- Check-out Time
- Cleaning Time
- Cleaning Status (Pending/In Progress/Completed)
- Issues Found
- Maintenance Required
- Assigned Date
- Priority

### 6. **Check-in/Check-out**
- Reservation ID
- Guest Name
- Room Number
- Check-in Date & Time
- Check-out Date & Time
- Actual Check-in Time
- Actual Check-out Time
- Rate Charged
- Extras (Room Service, etc.)
- Deposit Received
- Refund Due
- Notes

### 7. **Billing**
- Invoice ID
- Reservation ID
- Guest Name
- Room Number
- Check-in Date
- Check-out Date
- Number of Nights
- Rate per Night
- Room Charges
- Extra Charges (Room Service, etc.)
- Total Amount
- Discount
- Final Amount
- Payment Method
- Payment Status (Paid/Pending/Overdue)
- Payment Date
- Due Date
- Balance

### 8. **Accounting**
- Date
- Transaction ID
- Description
- Category (Room Revenue/F&B/Utilities/Payroll/etc.)
- Amount In
- Amount Out
- Balance
- Payment Method
- Notes
- Reconciled (Yes/No)

### 9. **Reports**
- Report Type dropdown
- Date Range
- Occupancy Rate

- Repeat Guests
- Booking Source Breakdown

- Check-in Time
